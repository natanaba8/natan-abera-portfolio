# My Portfolio Website

Hi! This is my personal portfolio site. I built it with **React** and **Vite**
while I was learning React, so the code is written in a simple way on purpose.
I tried not to use anything clever that I could not explain to someone else.

It is one single page. The menu links at the top do not open new pages, they
just scroll you down to the right part of the same page.

## What is on the page

1. **Navbar** - the bar at the top with my name and the menu
2. **Hero** - the big hello, my name, and a little card about me
3. **About** - a few paragraphs and a "Quick facts" box
4. **Skills** - three cards: Frontend, Backend, Tools
5. **Projects** - filter buttons and a grid of project cards
6. **Contact** - my details and a message form
7. **Footer** - the links again and the copyright line

## How to run it on your computer

You need **Node.js** installed first. Then open a terminal in this folder and
type these:

```bash
npm install     # downloads React and Vite. You only do this once.
npm run dev     # starts the site. It prints a link, open it in your browser.
```

The dev server is the one I use while working on it. When I save a file the
browser updates by itself, which is really nice.
